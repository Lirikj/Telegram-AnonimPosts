
AnonimPostsBot – это Telegram-бот для отправки анонимных сообщений в Telegram канал.


**🚀 Возможности**
- Анонимные сообщения – отправляйте сообщения в канал без указания автора.
- Гибкая настройка – укажите, в какой канал будут отправляться сообщения.
- Простота использования – бот не требует сложной настройки для пользователей.


**💎 Anonka Premium**

Для пользователей, которым нужны дополнительные функции, доступна подписка Anonka Premium:
- ⭐ Особый значок – выделяйтесь среди других пользователей.
- 📌 Закрепление сообщений – оставляйте важные посты наверху.
- ⏳ Отключение таймера – отправляйте сообщения в любое время.
- 📝 Редактирование сообщений – изменяйте уже опубликованные посты.
- 🚫 Отключение рекламы – пользуйтесь ботом без рекламных объявлений.
- 🗑️ Удаление сообщений – удаляйте свои сообщения в любое время.
- ❓ Создание опросов – создавайте анонимные или публичные голосования.
