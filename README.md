# Анонимка

Бот для отправки анонимных (почти) постов в Telegram-канал.  
Что-то вроде маленькой социальной сети или городской стены, где каждый может высказаться в рамках телеграм-канала.

Модерация осуществляется на основе нейросетевой модели OpenAI **omni-moderation-latest**.  
Подписка **Anonka Premium** открывает дополнительные возможности для пользователей.

## Возможности 🌟 Anonka Premium

1. ⭐️ **Особый значок** — Подписчики могут выбрать уникальный значок, выделяющий их среди других.  
2. 📌 **Закрепление сообщений** — Закрепляйте важные сообщения, чтобы их заметило больше людей.  
3. ⏳ **Отсутствие таймера** — Ваши сообщения остаются без ограничений по времени.  
4. 📝 **Редактирование сообщений** — Редактируйте свои сообщения для удобства.  
5. 🚫 **Отключение рекламы** — Общение без рекламных объявлений.  
6. 🗑️ **Удаление сообщений** — Удаляйте нежелательные сообщения в любой момент.  
7. ❓ **Создание опросов** — Анонимные или публичные голосования прямо через бота.

## Зависимости

- [pyTelegramBotAPI](https://pypi.org/project/pyTelegramBotAPI/) (`telebot`)  
- [openai](https://pypi.org/project/openai/)  


## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Lirikj/anonimka.git](https://github.com/Lirikj/Telegram-AnonimPosts/
cd anonimka
```

2. Установите зависимости 
```bash
pip install pyTelegramBotAPI openai
```

3. Настройте .env 

```
# Telegram
BOT_TOKEN=API_TELEGRAM
# OpenAI
OPENAI_API_KEY=API_OPENAI

# Каналы и админ
CHANNEL_DEVELOPERS=-12345678
CHANNEL_OSN=айди_канала_где_будут_публиковаться_посты
CHANNEL_OSN_THREAD=21012
ADMIN=12345678

# Эмодзи
EMOJI_GLAV=💌

```

4. Запустите бота

```bash
python main.py
```
